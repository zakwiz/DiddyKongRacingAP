# Diddy Kong Racing - Archipelago

An Archipelago implementation for Diddy Kong Racing.

## Installation instructions

1. Install [Archipelago](https://archipelago.gg/) and [Bizhawk](https://tasvideos.org/Bizhawk).
2. Download `connector_diddy_kong_racing.lua` and `diddy_kong_racing.apworld` from [the latest release](https://github.com/zakwiz/DiddyKongRacingAP/releases).
3. Add the `.apworld` to Archipelago's `worlds/` folder.
4. Add the `.lua` file to Archipelago's `data/lua/` folder.
5. Open the Diddy Kong Racing client.
6. Select a Diddy Kong Racing 1.0 ROM for patching.
7. Open the patched Diddy Kong Racing ROM (in Archipellago folder) in Bizhawk.
8. In Bizhawk, open *Tools > Lua Console*.
9. Select *Script > Open Script* and open `connector_diddy_kong_racing.lua`
10. Configure `.yaml` files for each player, (including DKR), then generate and host the Archipelago.
11. Connect the Diddy Kong Racing client to the Archipelago room.

If done correctly, you should see "Successfully Connected to N64" in the DKR client.
